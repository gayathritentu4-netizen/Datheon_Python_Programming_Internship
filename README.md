# Datheon Python Programming Internship

## About the Internship

This repository contains three Python projects completed as part of the Datheon Python Programming Internship. These projects demonstrate practical programming skills, logical thinking, problem-solving, data handling, and application development using Python.

## Projects Completed

### Task 1: Hangman Game

**Description:**

A terminal-based word guessing game developed using Python. The player attempts to guess a hidden word letter by letter within six incorrect attempts.

**Features:**
- Random selection of a secret word using `random.choice()`.
- Displays hidden letters using underscores.
- Allows users to guess one letter at a time.
- Tracks previously guessed letters.
- Prevents duplicate guesses from reducing attempts.
- Displays ASCII gallows art based on incorrect guesses.
- Announces win or loss based on the result.

**Technologies Used:**
- Python 3
- Random Module
- ASCII Art

### Task 2: Stock Portfolio Tracker

**Description:**

A Python-based application developed to track stock portfolio investments and analyze portfolio performance.

**Features:**
- Tracks stock portfolio information.
- Calculates investment profit and loss.
- Uses stock market data.
- Handles portfolio information using CSV files.
- Generates portfolio summaries.

**Technologies Used:**
- Python
- Pandas
- CSV File Handling
- Jupyter Notebook

### Task 3: Rule-Based Interactive Chatbot

**Description:**

A Python-based interactive chatbot that responds to user questions using predefined rules, keywords, and frequently asked questions.

**Features:**
- Interactive conversations with users.
- Identifies keywords from user messages.
- Provides predefined responses.
- Stores FAQ information using JSON.
- Provides a web interface using Streamlit.
- Deployed using Streamlit Community Cloud.

**Technologies Used:**
- Python
- Streamlit
- JSON
- Git and GitHub
